# MediBuddy Insurance Data Analysis & Machine Learning Capstone

## Project Overview
This project analyzes medical insurance data and develops machine learning models to predict insurance charges based on customer attributes.

The project includes data preprocessing, exploratory data analysis (EDA), data visualization, model training, evaluation, and hyperparameter tuning.

## Objectives
- Analyze medical insurance data.
- Explore relationships between customer features and insurance charges.
- Perform data preprocessing and exploratory data analysis.
- Train and evaluate multiple machine learning models.
- Compare model performance.
- Optimize the Gradient Boosting model through hyperparameter tuning.

## Dataset Features
- Age
- Sex
- BMI
- Children
- Smoker
- Region

**Target variable:** Insurance Charges

## Machine Learning Models
- Linear Regression
- Random Forest Regressor
- Gradient Boosting Regressor
- Tuned Gradient Boosting Regressor

## Model Performance

| Model | MAE | RMSE | R² Score |
|---|---:|---:|---:|
| Linear Regression | 4181.19 | 5796.28 | 0.7836 |
| Random Forest | 2541.61 | 4582.97 | 0.8647 |
| Gradient Boosting | 2404.90 | 4328.15 | 0.8793 |
| Tuned Gradient Boosting | 2451.51 | 4349.46 | 0.8781 |

## Best Model
The Gradient Boosting Regressor achieved the best performance among the evaluated models before tuning.

- MAE: 2404.90
- RMSE: 4328.15
- R² Score: 0.8793
